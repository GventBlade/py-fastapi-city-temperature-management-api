# City Temperature Management API

Проєкт для керування даними про міста та автоматичного відстеження їхньої температури за допомогою FastAPI та асинхронної SQLAlchemy.

## Як запустити проєкт

1. **Встановіть залежності**:
   ```bash
   pip install fastapi uvicorn sqlalchemy aiosqlite httpx
Запустіть сервер:

Bash

uvicorn main:app --reload
Документація API: Після запуску перейдіть за адресою http://127.0.0.1:8000/docs для доступу до Swagger UI.

Дизайн-рішення
Асинхронність: Використано AsyncSession (SQLAlchemy) та httpx для запитів до зовнішнього API, що забезпечує високу продуктивність.

Джерело даних: Для отримання координат та погоди обрано сервіс Open-Meteo, оскільки він дозволяє працювати без API-ключів та має високу точність.

Обробка помилок: Реалізовано безпечне парсування JSON-відповідей (метод .get()) для запобігання падінню сервера при некоректних даних від зовнішніх сервісів.

Налаштування сесії: Використано expire_on_commit=False у налаштуваннях async_sessionmaker для стабільної роботи з об'єктами міст після збереження даних у базу.
